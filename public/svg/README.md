# Thư Mục Tài Nguyên SVG & Lottie (`public/svg/`)

Đặt các file `.svg` hoặc hoạt hình Lottie `.json` tải từ bên ngoài vào thư mục này để sử dụng trong video thông qua `staticFile("svg/ten-file.svg")`:

- **Tra cứu mã Iconify (không cần tải file):** https://icones.js.org/
- **Tải file Vector SVG phức tạp:** https://www.svgrepo.com/
- **Tải Minh họa phẳng (Illustrations):** https://undraw.co/illustrations
- **Tải Bản đồ SVG Thế giới / Quốc gia:** https://simplemaps.com/resources/svg-maps
- **Tải Hoạt hình Lottie JSON:** https://lottiefiles.com/
